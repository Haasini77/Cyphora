# 🛡️ Cyphora

### Digital Crime Investigation Platform

> **Trace the clues. Uncover the truth.**

Cyphora is an interactive digital crime investigation platform built with Java Spring Boot and MongoDB.

It allows investigators to explore cyber-crime cases, analyze digital evidence, examine suspects, and identify the person responsible for an incident.

---

## 🚀 Features

- 🔐 Investigator Registration & Login
- 📁 Multiple Cyber-Crime Cases
- 🔎 Digital Evidence Investigation
- 🌐 IP Address Analysis
- 💻 Device Information
- 📄 File Access Logs
- 👤 Suspect Investigation
- ⚖️ Suspect Accusation System
- 🎯 Investigation Progress Tracking
- 📊 Investigation Result & Score
- 🗄️ MongoDB Database Integration
- 🌐 Interactive Web Interface

---

## 🕵️ Investigation Cases

### Case 001 — Zero Trace

Investigate a suspicious login in a computer lab and uncover unauthorized access to sensitive student records.

### Case 002 — The Vanished Device

Investigate a missing laptop using network traces, device information and file activity.

### Case 003 — Identity Unknown

Investigate a compromised account and trace the suspicious session back to its source.
